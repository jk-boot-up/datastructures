1. Static Array (Generic, Recursive)

Hello, and welcome. This video explains the generic, recursive static array, in C. This video is presented by Jayasekhar Konduru. First, a simple definition. It is a static array written once for any element type, as bytes with an element size, whose operations call themselves. Each call handles one element, asks a comparison function, and passes the rest to the next call, until a base case stops it. Our example is a weather station's week, as day names, temperatures, and readings. By the end, you will know how generic code and recursion work together in C, and what each one costs.

2. The Everyday Idea

Picture a queue of seven helpers, each standing by one box. You hand the first helper a card, and a rule for comparing a box with the card. If the box does not match, the helper passes the card and the rule to the next helper, and waits. The boxes could hold anything. The rule is what knows how to compare them. When someone finds a match, or the queue runs out, the answer travels back to you.

3. The Words

The words. The element size is how many bytes one element takes. A comparison function returns negative, zero, or positive. The base case answers without calling again. The recursive case handles one element and calls itself on the rest. And the recursion depth, the number of frames at once, is the extra memory used.

12. Act Five — The limit of recursion

And the limit. Binary search on a million integers is only twenty calls deep. Linear search needs one frame per element, and the call stack runs out. The operating system stops the program. So the demo ran it in a separate child process. Generics change what is stored. Recursion changes how much stack is used.

Here are the two depths. Twenty frames for binary search. A million frames for linear search, far beyond what the stack can hold.

14. Time and Space Complexity

Here are the costs. Get and update are order one, and not recursive. Traversal, linear search and find max take order n time, and order n stack. Binary search takes order log n time and stack. Insertion and deletion at the front take order n time and stack. The loop versions take the same time, with order one extra space.

15. The Four Static Arrays

How do the four static arrays compare? The int array with loops is the fastest, and the compiler checks its type. The recursive int array adds a stack frame per waiting call. The generic array with loops holds any type, without type checks. And this one does both. The void pointer changes what is stored. Recursion changes how much stack is used.

16. Common Mistakes

Four mistakes to watch for. A recursion with no base case, or no progress towards it. Comparing strings or structs with double equals. Passing the wrong element size. And linear recursion on large data, which overflows the stack.
