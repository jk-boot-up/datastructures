1. Static Array (Generic)

Hello, and welcome. This video explains the generic static array, in C. This video is presented by Jayasekhar Konduru. First, a simple definition. C has no type parameters. So a generic array is a block of bytes, with an element size, and comparison functions passed in. It is exactly how the standard library's quick sort works. Our example is a weather station's week, stored three different ways by the same code. By the end, you will know how to hold any type in C, how comparison functions work, and what it costs.

2. The Everyday Idea

Picture a row of identical lockers, and a caretaker who is told only one thing: every box here is twelve centimetres wide. The caretaker finds locker three at once, three times twelve centimetres along. And can move boxes along, without knowing what is inside. To compare two boxes, the caretaker needs a helper who knows the contents. That helper is the comparison function.

3. The Words

The words. Void pointer: a pointer to memory of unknown type. Element size: how many bytes one element takes. Mem copy: copies bytes without knowing what they mean. A comparison function returns negative, zero, or positive. And type safety is what the void pointer gives up.

4. Act One — One array type, any element type

First, one array type, for any element type. The same functions hold the temperatures, as integers. They hold the day names. And they hold readings, a struct of our own. But there is a catch. The compiler cannot check the type any more. Passing a day name to the array of temperatures would compile without a warning.

8. Act Three — Searching with comparison functions

Now searching. The array cannot compare elements itself, so every search is given a comparison function. For the day names, the function uses string compare, which compares the letters. So a day name typed by the user is found. Double equals would compare the addresses, and say they are different. Binary search uses the same function to decide which half to keep: three comparisons.

Insertion and deletion work as before, with whole elements. Inserting a reading at index two shifts five readings, twelve bytes each. Deleting index zero copies the reading out, and shifts seven. And when all ten places are used, the next insertion is an overflow.

12. Act Five — One algorithm, many orders

One algorithm, many orders. Find max is written once. Given the comparison of temperatures, it returns Thursday. Given the comparison of names, it returns Wednesday. The order lives in the function you pass in. And that is exactly how the standard library's quick sort and binary search work.

14. Time and Space Complexity

Here are the costs. They are the same as the int array. Access and update are order one. Traversal, linear search, maximum and reverse are order n. Binary search is order log n. Insertion and deletion at the front are order n. Each comparison is now a function call, which costs a little time.

15. Compared With Related Structures

How does it compare? The int array is typed, and the compiler checks it. The generic array holds any type, and the compiler cannot check it. Java's generics hold any type and are checked, because the language has type parameters. And like every static array, the capacity is fixed.

16. Common Mistakes

Four mistakes to watch for. Passing the wrong element size, such as the size of a pointer instead of the struct. In an array of pointers, forgetting to dereference once in the comparison. Returning x minus y, which can overflow. And comparing strings with double equals.
