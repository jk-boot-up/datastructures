# Prerequisites — Static Array

## You need

- C basics: variables, `for` and `while` loops, functions and structs
- What `int` and a pointer are

## You do not need

- Any previous data-structures knowledge
- Big-O notation (START-HERE.md introduces it by counting steps)

## If any of that is new

[Start here](../../../START-HERE.md) explains memory, pointers and counting steps from the beginning.

## What to install

- A C compiler and `make`. On macOS, `xcode-select --install`; on Linux, the `build-essential` (Debian, Ubuntu) or `gcc make` packages. No libraries.

- About an hour for the session guide.
