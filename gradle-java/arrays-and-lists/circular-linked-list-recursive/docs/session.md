# Session Guide — Circular Linked List (Recursive)

## By the end you can

- Choose the base case of a recursion on a circle: last, not null.
- Write recursive laps that find nodes, and O(1) linking.
- Derive and use the Josephus formula.

## Walkthrough

Ask what the base case of count should be on a circle, and let the class discover that null never comes. Run the demo; in act one, trace count round the table. In act four, derive the Josephus formula from one round of the game. Finish with the StackOverflowError and the loop version of the formula.
