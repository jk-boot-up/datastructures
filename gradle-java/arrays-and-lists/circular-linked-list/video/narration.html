1. Circular Linked List

Hello, and welcome. This video explains the circular linked list, in Java. This video is presented by Jayasekhar Konduru. First, a simple definition. A circular linked list is a linked list whose last node points back to the first. There is no end, and no null. The list keeps one pointer, to the last node, and the first node is the one after it. Our example is players taking turns round a board game. By the end, you will know every textbook operation on a circular list, what each one costs, and the loop that never stops.

2. The Everyday Idea

Picture friends sitting round a table, playing a board game. When your turn ends, you pass the dice to your left. After the last person, the dice simply carry on to the first person again. A circle has no last seat. Nobody ever has to say, we have reached the end, go back to the start. That is a circular linked list.

3. The Words

The words. Circular: the last node's next pointer is the first node. Last is the only pointer the list keeps. The first node is last dot next. And a traversal is a do while loop, which stops when it is back at the start.

Now join the ends. Dan's next pointer points back to Ann. The list keeps just one pointer, last, to Dan. The first player is last dot next: Ann. So both ends are one step away, and inserting at the end walks nowhere.

8. Act Three — Turns, insertion and deletion

Now the textbook operations. Six turns take six steps, with no special case. Inserting at the beginning or at the end walks nowhere. At the end, it inserts at the beginning, and then moves last on. Deleting at the beginning changes one pointer. But deleting at the end must walk round to the node before last.

10. Act Four — Waiting for null

What if a loop waits for null? There is none. The loop went round and round, a thousand steps, until it was stopped. A circular list is traversed with a do while loop, which stops when it is back at the start. And a list of one node points to itself.

14. Time and Space Complexity

Here are the costs in time and space. Inserting at the beginning or the end is order one. Deleting at the beginning is order one. Deleting at the end is order n, because the node before last must be found. Search, display and count are order n. And the next turn is always one step.

15. Compared With Related Structures

How does it compare? Inserting at the end is order one in a circular list, and order n in a singly list with only a head. Deleting at the end is order n here, and order one in a doubly linked list. After the last node, a circular list goes back to the first, where the others reach null.

16. Common Mistakes

Four mistakes to watch for. Waiting for null, which never comes. A while loop that checks before its body, and so never starts. Forgetting that a single node points to itself. And deleting the last node without moving the last pointer.
