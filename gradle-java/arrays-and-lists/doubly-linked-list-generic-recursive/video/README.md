Suggested description:

> Generic Recursive Doubly Linked List in Java, explained with a photo viewer of Photo records. We trace a recursive search along prev pointers from the tail, comparing with equals until a separately made Photo("dog", 610) matches. We count Integers and display Strings with the same recursion, insert at both ends with no recursion at all, and find nodes recursively before linking them in O(1): insertAtPosition two calls deep with four pointers, deleteByKey three calls deep with two. We reverse the album recursively, seven calls deep, and finish at the limit: counting a million nodes throws a real StackOverflowError.
