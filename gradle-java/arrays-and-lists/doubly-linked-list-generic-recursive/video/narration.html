1. Doubly Linked List (Generic, Recursive)

Hello, and welcome. This video explains the generic, recursive doubly linked list, in Java. This video is presented by Jayasekhar Konduru. First, a simple definition. It is a doubly linked list for any type of data, whose walks are recursive, along either pointer. Elements are matched with equals, and finding is recursive while linking is one step. Our example is a photo viewer. By the end, you will see generics and recursion working together on nodes with two pointers.

2. The Everyday Idea

Think of guards on a train carrying any cargo. Each guard checks their own carriage, and if the crate is not there, asks the next guard along, forwards or backwards, and waits. Each guard only needs to know how to compare two crates.

3. The Words

The words. A node of T has previous, data, and next. Equals compares contents. Finding is recursive, linking is one step. And the depth is one frame per node walked.

12. Act Five — The limit of recursion

And the limit. Counting a million nodes recursively overflows the stack. Generics change what a node refers to. Recursion changes how much stack a walk needs.

14. Time and Space Complexity

Here are the costs. Both ends are order one, with no recursion. Walks take order n time and stack. In the middle, finding is order n and linking order one. The loop version takes the same time, with order one space.

15. The Four Doubly Linked Lists

The four doubly linked lists. Strings with loops, strings with recursion, any type with loops, and any type with recursion. On a million nodes, only the loops finish.

16. Common Mistakes

Four mistakes. Matching with double equals. Recursing on next after the swap in reverse. Recursing to reach an end. And recursing over long lists.
