1. Doubly Linked List (Generic)

Hello, and welcome. This video explains the generic doubly linked list, in Java. This video is presented by Jayasekhar Konduru. First, a simple definition. It is a doubly linked list written once for any type of data. Each node has a previous pointer, a reference to its data, and a next pointer. Our example is a photo viewer. By the end, you will know how Java's linked list is built, and why its costs do not depend on the type.

2. The Everyday Idea

Think of a train, coupled front and back. Its carriages can carry anything: passengers, coal, cars. The couplings work the same whatever is inside. That is a generic doubly linked list.

3. The Words

The words. A node of T has a previous pointer, data of type T, and a next pointer. The list keeps head and tail. The data is a reference. And equals compares contents.

12. Act Five — The same algorithm for every type

One algorithm for every type. Reverse swaps the pointers of every node, then head and tail. Twelve pointer changes for the sizes, and the same twelve for the names. Generics change the type, not the algorithm.

14. Time and Space Complexity

Here are the costs. Insertion and deletion at both ends are order one. Deleting a node already reached is order one. Reaching a position is order n. Search, count, display and reverse are order n. Exactly as in the string-only list.

15. Compared With Related Structures

How does it compare? The string-only list has the same costs, for one type. A generic singly list deletes at the end in order n. A generic dynamic array reaches any position in one step. And Java's own linked list is this structure.

16. Common Mistakes

Four mistakes. Matching with double equals. Forgetting one of the four insertion pointers. Using raw types. And not updating the head or tail at the ends.
