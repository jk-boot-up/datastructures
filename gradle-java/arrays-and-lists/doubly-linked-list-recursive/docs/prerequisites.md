# Prerequisites — Doubly Linked List (Recursive)

## You need

- The doubly-linked-list and singly-linked-list-recursive projects

## You do not need

- Functional programming

## If any of that is new

[Start here](../../../START-HERE.md) explains memory, references and counting steps from the beginning.

## What to install

- Nothing but a JDK. The Gradle wrapper downloads Gradle, and the build downloads JDK 25 itself if your machine does not have it.

- About an hour for the session guide.
