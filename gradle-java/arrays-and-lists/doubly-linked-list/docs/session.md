# Session Guide — Doubly Linked List

## By the end you can

- Draw a doubly linked list with head, tail, prev and next.
- Implement insertion and deletion at both ends in O(1), and in the middle with four and two pointers.
- Explain why deleting a node already reached is O(1).
- Reverse the list by swapping pointers, and state every operation's complexity.

## Walkthrough

Start with the train analogy. Run the demo; in act one, ask how a singly list goes back. In act three, draw the four pointers of insertAtPosition on the board. In act four, remove one arrow and walk backwards. In act five, reverse on paper by swapping arrows. Finish with the comparison table and point to the LRU cache.
