# Session Guide — Dynamic Array (Generic, Recursive)

## By the end you can

- Write recursive methods in a generic class.
- Explain that a recursive resize copies references, one frame each.
- State the time and stack space of each operation.
- Explain why the append can overflow the call stack.

## Walkthrough

Recall both earlier projects. Trace the recursive copy of references on the board and show that the objects do not move. Run the demo; in act three, trace the recursive equals search. In act five, show the StackOverflowError and compare with ArrayList.
