1. Dynamic Array (Generic, Recursive)

Hello, and welcome. This video explains the generic, recursive dynamic array, in Java. This video is presented by Jayasekhar Konduru. First, a simple definition. It is an array that grows by itself, written once for any type, whose loops are all written as recursions. It stores references, compares with equals, and copies one reference per call when it resizes. Our example is a playlist of songs. By the end, you will know how generics and recursion work together, and why an append can overflow the stack.

2. The Everyday Idea

Think of a list of warehouse addresses, being copied onto a longer sheet by a line of helpers. The first helper copies line zero, then asks the next helper to copy the rest, and waits. Each helper copies one address, and waits. The furniture never moves, only the addresses. When no lines are left, everyone can go home. A million lines would need a million helpers in the corridor.

3. The Words

The words. T is the element type. Each place holds a reference, and a resize copies the reference, not the object. Equals compares contents. The base case is when nothing is left. And the recursion depth is the number of frames at once.

First, a recursive copy of references. The playlist is full with four songs. To append a fifth, it resizes. Copy zero copies the reference to Blue Sky, and calls copy one. And so on, until copy four finds nothing left, the base case. Four frames deep. The songs themselves never move.

12. Act Five — The limit of recursion

And the limit. A million appends. Long before the end, a resize must copy more references than the call stack can hold frames for. A stack overflow error, from inside an ordinary append. Generics change what is stored. Recursion changes how much stack is used.

13. The limit of recursion

One frame per reference. For a large resize, far too many.

14. Time and Space Complexity

Here are the costs. Get and update are order one. Append is order one amortised, but a resize takes order n time and stack. Insertion and deletion at the front take order n time and stack, and so does linear search. The loop version takes the same time, with order one extra space.

15. The Four Dynamic Arrays

The four dynamic arrays. The string version with loops. The string version with recursion. The generic version with loops, which is Java's array list. And this one, generic and recursive. On a million appends, only the loop versions finish.

16. Common Mistakes

Four mistakes to watch for. Writing new T array. Searching with double equals. A recursive copy inside resize, which overflows on large lists. And not clearing freed places.
