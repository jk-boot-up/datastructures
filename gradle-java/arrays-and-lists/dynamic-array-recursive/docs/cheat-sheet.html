Dynamic Array (Recursive) — Cheat Sheet

The recursive dynamic array doubles when full and halves when a quarter full, like any dynamic array, but copies, shifts, traverses and searches recursively: the time is unchanged, and the extra space is one call-stack frame per element, so a large resize can overflow the stack.

What it isThe recursive dynamic array grows and shrinks like any dynamic array, but copies, shifts, traverses and searches by calling itself on the rest, so each operation keeps its time and gains O(n) stack, and a large resize overflows.

Use it whenLearning how each loop of a dynamic array becomes a recursion, with its base case; Small arrays, where the depth stays far below the call-stack limit
Avoid it whenAny array that may grow large: a recursive resize of a few tens of thousands of elements can overflow the call stack. Use the loops of dynamic-array; Performance-sensitive code: each call costs a frame, a jump and a return
Already in JavaNothing: Java's ArrayList grows with a loop (Arrays.copyOf)

Watch out for

  • A resize copy with no base case: Stop at i == size, the number of elements, not the new capacity.
  • Forgetting that resize is recursive: Keep hidden, linear work such as copying as a loop.
  • Shifting from pos upwards on insertion: Start shiftRight at the last element and move down to pos.
  • Not clearing a deleted place: Set the freed place to null.
