# Session Guide — Singly Linked List (Generic)

## By the end you can

- Write `Node<T>` and a generic list class.
- Explain that a node refers to its data rather than copying it.
- Match elements with equals and explain why == is wrong.
- State that every cost is unchanged from the String-only list.

## Walkthrough

Show the String-only list and ask how to hold distances. Replace String with T; note that no cast is needed, unlike a generic array. Run the demo; in act two, draw a node with two arrows. In act three, show equals finding a separately made Clue. Finish with the comparison table.
