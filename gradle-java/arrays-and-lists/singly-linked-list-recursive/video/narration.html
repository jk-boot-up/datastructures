1. Singly Linked List (Recursive)

Hello, and welcome. This video explains the singly linked list, written recursively, in Java. This video is presented by Jayasekhar Konduru. First, a simple definition. Seen recursively, a list is either empty, or a node followed by a smaller list. So every operation handles one node, and calls itself on the rest, until it reaches the empty list. Our example is a treasure hunt of clues. By the end, you will know how to count, print backwards, delete and reverse a list recursively, and what the call stack costs.

2. The Everyday Idea

Think of a treasure hunt run by a team of finders, one for each clue. You ask the first finder how many clues are left. They say: one, plus however many the next finder counts. And they wait. The next finder says the same, and waits. After the last clue there is nobody, and the answer is zero. That is the base case. Then the answers come back, each finder adding one.

3. The Words

The words. A list is either empty, or a node followed by a smaller list. The base case is the empty list, or the node you are looking for. The recursive case handles this node, and calls itself on the next. A method that changes the list returns the new first node. And the depth is one frame per node visited.

12. Act Five — The limit of recursion

And the limit. We build a million nodes, inserting at the beginning, with no recursion at all. Then we count them recursively. One frame per node. The call stack runs out, and Java throws a stack overflow error. The loop version counts them with order one extra space.

13. The limit of recursion

One count call per node, all waiting. A million is far too many.

14. Time and Space Complexity

Here are the costs. Insertion and deletion at the beginning are order one, and not recursive. Count, display and search are order n time, and order n stack. So are insertion and deletion at the end, and reverse. The loop version takes the same time, with order one extra space.

15. Recursive or Loop?

Recursive or loop? Every operation takes the same time either way. Recursion adds one frame per node. Some operations are simpler recursively: display in reverse, delete by key, and reverse. But on a million nodes, only the loop finishes.

16. Common Mistakes

Four mistakes to watch for. Calling the recursive method without storing the node it returns. Forgetting the base case for the empty list. In reverse, forgetting to set the next pointer to null, which makes a cycle. And recursing over a long list.
