# Session Guide — Singly Linked List

## By the end you can

- Draw a singly linked list with head, nodes, next pointers and null.
- Implement insertion and deletion at the beginning, the end and a position, and deletion by key.
- Explain why the order of the two pointer changes in an insertion matters.
- Reverse a list with prev, current and next, and state every operation's complexity.

## Walkthrough

Start with the treasure-hunt analogy and draw the nodes as boxes with arrows. Run the demo; in act two, ask why count needs a traversal. In act three, perform insertAtPosition on the board in both orders. In act four, show the self-loop. In act five, trace reverse with three fingers for prev, current and next. Finish with the comparison table and point to the doubly linked list.
