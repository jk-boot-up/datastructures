# Session Guide — Skip List

## By the end you can

- Draw a skip list with its levels and head.
- Search it by riding each level and dropping down, and count the hops.
- Insert and remove on every level a node stands on.
- Explain why the coin makes it fast on average, and what an unlucky coin does.

## Walkthrough

Start with the railway analogy and a drawn line of stations with an express above it. Run the demo; in act one, count the thirteen hops. In act two, draw the four levels. In act three, trace the search for Marden with a finger and say out loud 'too far, change down' at each drop. In act four, toss a real coin for a few stations to show how heights come about, then imagine it always landing tails. Close with act five's numbers and the harder exercise's argument for two arrows per station.
